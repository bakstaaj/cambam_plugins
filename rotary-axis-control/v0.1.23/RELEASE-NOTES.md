# Rotary Axis Control release v0.1.23

- Hide CamBam lower properties inspector while Rotary Control is selected.
- Expand the machine-control tab area to use the available sidebar height, then restore the properties inspector when switching to another tab.
- Preserve the rotary control, simulator, serial, Ethernet, preview, and UI features from v0.1.19.

The properties-pane behavior was installed and confirmed in CamBam. Rotary hardware and Ethernet controller operation remain firmware-dependent and were not validated as part of this UI change.
