# CamBam Plugins

Standalone plugins for CamBam 1.0 x64. Each plugin has its own versioned source folder and install package.

| Plugin | Current version | What it does |
| --- | --- | --- |
| [Rotary Axis Control](rotary-axis-control/v0.1.19/README.md) | 0.1.19 | GRBL-derived controller panel with configurable rotary-axis display, jogging, indexing, an XYZ/A/B/C simulator, and serial or Ethernet TCP/IP connections. |
| [Tapping](tapping/v0.1.1/README.md) | 0.1.1 | Creates clearance-hole Spiral Mill and internal ThreadingMOP pairs from the CamBam `cutout` style, selecting tools from the active library. **Requires the compatible CamBam 1.0 x64 ThreadingMOP plugin installed first.** |
| [Hole Drilling](hole-drilling/v0.1.1/README.md) | 0.1.1 | Groups selected hole circles and creates Spiral Mill Drill MOPs based on the CamBam `cutout` style, with the largest suitable EndMill. |
